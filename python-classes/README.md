# Python - Classes and Objects

Introduction to object-oriented programming in Python: classes, instances,
private attributes, properties, getters and setters, using a `Square` class.

## Files

- `0-square.py`: empty class
- `1-square.py`: private size
- `2-square.py`: size validation
- `3-square.py`: area
- `4-square.py`: size property and setter
- `5-square.py`: printing with `#`
- `6-square.py`: position
