# Python - Everything is Object

This project covers Python object model concepts.

## Concepts

- `id()` and `type()` - identity and type of an object
- Mutable objects: `list`, `dict`, `set`, `bytearray`
- Immutable objects: `int`, `float`, `complex`, `str`, `tuple`, `frozenset`, `bytes`
- Assignment vs referencing / aliases
- `==` vs `is`
- How arguments are passed to functions (by assignment)
- Integer pre-allocation / small-int cache
- Tuples and frozen sets containing mutable objects

## Files

- `0-answer.txt` to `28-answer.txt` - answers to object identity questions
- `19-copy_list.py` - function returning a copy of a list
