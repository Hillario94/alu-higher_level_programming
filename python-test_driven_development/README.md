# Python - Test-driven development

This project covers writing documentation and tests first, using doctest
and unittest.

## Files

- `0-add_integer.py`: adds two integers or floats
- `2-matrix_divided.py`: divides all elements of a matrix
- `3-say_my_name.py`: prints a full name
- `4-print_square.py`: prints a square with `#`
- `5-text_indentation.py`: prints text with 2 new lines after `.`, `?` and `:`
- `6-max_integer.py`: finds the max integer in a list
- `tests/`: doctest files (`.txt`) and unittest files (`.py`)

## Running the tests

Doctest: `python3 -m doctest ./tests/*.txt`

Unittest: `python3 -m unittest tests.6-max_integer_test`
