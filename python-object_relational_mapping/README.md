# Python - Object-relational mapping

Scripts that connect Python to MySQL, first with `MySQLdb` (tasks 0 to 5)
and then with the `SQLAlchemy` ORM (tasks 6 to 14).

## Requirements

- MySQL 8.0 running on localhost:3306
- `mysqlclient` (MySQLdb 2.0.x) and `SQLAlchemy` 1.4.x

## Usage

    ./0-select_states.py <user> <password> <database>
    ./2-my_filter_states.py <user> <password> <database> <state name>
